`Next.js` `React` `Supabase` `Paddle` `Sentry` `Anthropic API`

opening and closing balances printed on the statement — in application code, not
by asking the model to confirm its own work. When it doesn't reconcile, the app
says so and shows which rows to look at. A quiet wrong answer is the expensive
kind.
